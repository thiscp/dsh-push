== pitfall 2: the probes old sidebar detector is stale on the current bundle ==
sidebarState() selects [class*=_root_] (trailing underscore). The current bundle class is hHd-Xa_root (no trailing underscore),
so it returns {expanded:null,sidebar:null} even though the sidebar is open and 280px wide. Not an app defect - a probe limitation.
The D10STATE content probe (text New Session + Settings/Plugins, widest 100..92%vw box >=50%vh, plus elementFromPoint hit test)
is the reliable detector and is what the d10 mode reports. Same for the old nav helper log line no collapse button, which only
means the sidebar was already collapsed when the session row was clicked.
