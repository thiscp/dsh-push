# 高分屏适配：壁纸与宠物素材提清 + 手机分辨率实测

## Why

用户真机 iQOO 13 为 2K 屏（超清 3168×1440 / 高清 2376×1080 可切换，densityDpi 随之变），模拟器是 1080×2400@420dpi。布局与立绘均为 dp 尺寸 + 矢量场景 + nodpi 位图——**dp 自适应框架本身是对的**（官方推荐，物理尺寸跨设备一致，分辨率切换自动按新密度重绘）。但两处位图源分辨率低于 2K 屏显示尺寸，真机上发糊：

- `bg_whale.webp`（日间壁纸）1280×720，CENTER_CROP 到 1440×3168 需放大 **4.4×**
- `pet_*.png` 238×260，150dp 在 560dpi 显示 525px，放大 **2.2×**（通知大图标同源）

五张新立绘 935×1682 在 300dp@560dpi 显示 1050px（1.12×），基本无损，无需处理。

## What Changes

- vm1 用 PIL Lanczos 提清（无网络素材可换，日间图是 yunxi 唯一原图）：
  - `bg_whale.webp` 1280×720 → 2560×1440（q80 webp，CENTER_CROP 放大倍数降到 2.2×）
  - `pet_*.png` ×4 238×260 → 476×520（Lanczos 保 alpha，通知大图标一并受益）
- 版本 1.23.0（versionCode 54）
- 模拟器 `wm size 1440x3168` + `wm density 560` 复刻真机超清逐主题截图；再 `wm density 440` 模拟超清→高清运行时切换，验证不闪退、按新密度重绘；测完 `wm size reset` + `wm density reset`

## Impact

- 受影响 spec：`companion-app`（小清新视觉主题——补高分屏清晰度与分辨率切换场景）
- APK 体积 +约 0.6MB（提清后位图）
- 无代码逻辑改动（纯素材 + 验证）
